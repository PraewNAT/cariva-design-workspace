# Button / shadcn

ใช้ recipe เดียวกันบนหน้า, DialogTrigger และ DialogClose (Base UI ใช้ `render={<Button/>}`)

| size                     | ขนาด           | text / line-height | padding แนวตั้ง |
| ------------------------ | -------------- | ------------------ | ------------- |
| sm                       | 32px           | 12 / 16            | 8px           |
| default                  | 40px           | 16 / 24            | 8px           |
| lg                       | 48px           | 16 / 24            | 12px          |
| icon-sm / icon / icon-lg | 32 / 40 / 48px | icon 24            | 4 / 8 / 12px  |

ความสูงเกิดจาก padding + line-height ไม่ใช่ height; outline ใช้ inset ring ไม่กินพื้นที่เพิ่ม Radius ตาม Product: carivaApp pill และ backOffice 12px ใช้ tokens เดิม ห้ามแก้ per-screen

Variants: default (Figma contained), outline (outlined), ghost (text) ใช้ร่วมกับ `color` = primary / destructive / secondary (Figma error = destructive, neutral = secondary) variant อื่นของ shadcn คือ secondary, destructive, link, decorative ไม่ใช้ `color` ยังไม่มี elevated (รอ shadow token) Loading ใช้ disabled + aria-busy + Spinner ไม่เพิ่ม loading prop ให้ primitive; bridge หน้าเก่าแปลง loading ให้เอง

Icon ใช้ currentColor และ data-icon เมื่อต้องระบุทิศทาง สี primary จาก Figma ยังมีข้อจำกัด contrast กับตัวอักษรขาว ไม่อ้างว่า AA ผ่านทั้งหมด

Decorative motion: `variant="decorative"` has the original Figma gradient with a continuous aura breathing through centered background-size (165%–100%) over 5s and stronger glow on fine-pointer hover while enabled. Disabled/aria-disabled and reduced-motion stay static. It adds no loading prop or audio/AI request behavior; other variants retain their appearance.
