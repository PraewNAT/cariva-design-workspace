# Keyboard — Figma reference (ไม่ใช่ component)

อ่านจาก Figma วันที่ 26 พฤศจิกายน 2026: หน้า Keyboard (`4485:37226`) ในไฟล์ Cariva Core Design System ผู้ใช้ยืนยันตามที่ Claude เสนอ กรอบเอกสาร `Documentation Card` (`7308:122323`) อยู่ในหน้านี้

หน้านี้เป็นภาพอ้างอิงแป้นพิมพ์ **G-Board** (ตัวอักษรอังกฤษและตัวเลข กว้าง 1280 และ 375) เป็น instance จากไลบรารีภายนอก สำหรับวางในแบบหน้าจอมือถือที่มีช่องกรอก

- **ไม่มีโค้ด** และ **ไม่มี Code Connect** เพราะแป้นพิมพ์จริงมาจากระบบปฏิบัติการ ไม่ใช่ component ของ DS
- วางแป้นพิมพ์ตามชนิดข้อมูลของช่อง: ตัวอักษร (Alphabetic) หรือตัวเลข (Numeric)
- ชิ้นส่วนไม่ได้ผูกตัวแปรของ DS และไม่มีแป้นพิมพ์ภาษาไทยในหน้านี้
- ห้ามเขียนเป็น component ใน Storybook
