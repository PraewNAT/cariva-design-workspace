This page is a reference for the **G-Board** keyboard (English letters and numbers, widths 1280 and 375), an instance from an external library, to place in mobile screen designs that have input fields

- **No code** and **no Code Connect**, because the real keyboard comes from the operating system and is not a DS component
- Place the keyboard by the field's data type: Alphabetic or Numeric
- The parts are not bound to DS variables, and there is no Thai keyboard on this page
- Do not write it as a component in Storybook
