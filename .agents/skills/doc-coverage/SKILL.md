# Documentation Coverage

Discover approved Core/Product components from actual source/exports/catalog, and distinguish starter examples and experimental previews. Compare them with existing Storybook/Markdown docs and agreed cases. Figma is an additional destination only when mapped or requested; missing Figma is not a failure for code-only work.

Report each component's code, docs, story/case and optional Figma coverage, with verified paths/IDs. Existence is distinct from successful render/testing. Do not require `.ai.md`, `.figma.tsx`, a separate Markdown document, or seven files unless the actual component contract requires them. Use implemented code for API facts and approved tokens/specification for visual rules.

Report only; no component generation, deletion, publishing or version numbering. State inaccessible scope and missing mappings honestly.
